# Anti-Slop Audit 002 · Task Switcher, Auto Location Weather & Radio Tuner Pipeline
Date: 2026-10-13
Scope: Android Native Launcher (`MainActivity.java`, `CarThermometerWatcher.java`, `dialog_task_switcher.xml`, `item_task_card.xml`, `view_setup.xml`, `PreferenceHelper.java`)
Design Language: Swiss Typographic Style (Automotive Cockpit Architecture)

---

## Executive Summary
This audit validates the implementation of the three cockpit subsystems requested by the driver:
1. Native Task Switcher Dialog modal (`dialog_task_switcher.xml` & `item_task_card.xml`) enabling foreground app switching and RAM termination on the 1GB/2GB Allwinner T3 head unit.
2. Dynamic vehicle location weather synchronization (`CarThermometerWatcher.java` & `GpsTelemetryManager.java`) with IP fallback, reverse geocoding city names, and cluster offset calibration.
3. Dedicated Radio Tuner Pipeline (`MainActivity.java`, `PreferenceHelper.java`, `view_setup.xml`) broadcasting vendor MCU tuner signals and launching car radio apps without ever opening Spotify.

## Numbered Findings List
1. **[LOW] Priority - R-27 (Task Card Memory Footprint Display)**:
   - *Finding*: Task cards currently display `RUNNING IN BACKGROUND` or `RECENT TASK · READY`.
   - *Recommendation*: Future enhancement can query `am.getProcessMemoryInfo(pids)` to display exact MB consumed per background app (e.g. `48 MB RAM`) next to the status.
2. **[LOW] Priority - R-03 (Automated Recent Task Purge on Low RAM)**:
   - *Finding*: Closing apps is currently user-triggered via `CLOSE` or `CLOSE ALL APPS`.
   - *Recommendation*: On Android head units with <= 1GB RAM, an optional background watchdog could automatically trim tasks when available memory drops below 150MB.
